# Docspace · Main Management

Version **0.0.2**

UI ใช้ภาษาอังกฤษทั้งหมด ทั้งเมนู ปุ่ม tooltip ข้อความสถานะ และข้อความแจ้งข้อผิดพลาด ชื่อไฟล์และเนื้อหาเอกสารแสดงตามต้นฉบับ

รวมโปรแกรมจาก Doc_management และ Heat-Map เป็นแอป Desktop หน้าต่างเดียว

ใช้เมนูด้านซ้ายสลับเครื่องมือ โดยรายการ PDF และค่าที่กรอกใน Heatmap ยังคงอยู่เมื่อสลับหน้า

- **PDF to Image**: เพิ่ม PDF หลายไฟล์ด้วยปุ่มหรือลากวาง ดูตัวอย่างแต่ละหน้า ซูม เลือกหน้าส่งออกเป็น JPG, PNG หรือ WebP และยกเลิกระหว่างทำงาน
- **จัดการหน้า PDF**: grid/list ภาพย่อรายหน้า ลากเรียงข้ามไฟล์ เลือกหลายหน้า หมุน ลบ ย้อนกลับ และรวม/แยก PDF ใหม่
- **Heatmap**: กรอกอุณหภูมิ 6 จุด ปรับพื้นที่ ตำแหน่ง ชื่อจุด ช่วงสี และขนาดภาพ ดูตัวอย่างและส่งออก PNG
- ทำงานภายในเครื่อง ไม่ต้องใช้เว็บเซิร์ฟเวอร์
- คัดลอกซอร์สที่จำเป็นมาไว้ในโฟลเดอร์นี้แล้ว สามารถใช้งานโดยไม่อ้างอิงสองโฟลเดอร์ต้นฉบับ
- ไฟล์งานและผลลัพธ์เดิมในสองโฟลเดอร์ต้นฉบับยังอยู่ที่เดิม เลือกเปิดหรือเลือกปลายทางจากหน้าจอได้

## เปิดใช้งานบน Windows

ดับเบิลคลิก `start_ui.vbs` หรือ `start_ui.bat`
ตัวเปิดโปรแกรมใช้ `.venv` ในโฟลเดอร์นี้ มีหน้าจอโหลดและบันทึกข้อผิดพลาดที่ `.webview/startup.log`

ติดตั้งใหม่เมื่อย้ายเครื่อง (Python 3.10+ และ Microsoft Edge WebView2 Runtime):

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

เปิดผ่านคำสั่ง:

```powershell
.\.venv\Scripts\python.exe main_app.py
```

## ฟังก์ชัน PDF ในเวอร์ชัน 0.0.2

- ลากไฟล์ PDF จาก File Explorer ลงบนหน้า PDF หรือแถบด้านซ้ายได้ โดยไม่มีข้อความหรือกล่องกำกับการลากวาง รองรับหลายไฟล์และไม่เพิ่มไฟล์เดิมซ้ำ ไฟล์ที่อ่านไม่ได้จะแสดงข้อผิดพลาดในรายการ
- เลือก PDF ในรายการ แล้วเลือก **Export pages** จาก dropdown: **All pages** (ทุกหน้า), **Current page** (หน้าที่แสดงในตัวอย่าง), **Custom pages** (ระบุหน้าเอง), **Even pages** (หน้าคู่) หรือ **Odd pages** (หน้าคี่) ใช้เลขหน้า PDF เริ่มจาก 1
- ช่องกรอกช่วงหน้าจะแสดงเฉพาะ **Custom pages** เช่น `1-3, 5` หรือ `1–3, 5` แต่ละ PDF มีตัวเลือกแยกกัน ค่าจะอยู่ระหว่างสลับไฟล์หรือเครื่องมือภายในรอบการเปิดแอป หากเลือกหน้าคู่ใน PDF ที่มีเพียงหน้าเดียว โปรแกรมจะแจ้งว่าไม่มีหน้าคู่
- ช่วงหน้าต้องอยู่ภายในเอกสาร เรียงจากน้อยไปมากภายในแต่ละช่วง โปรแกรมรวมเลขหน้าที่ซ้ำและส่งออกตามลำดับหน้า ชื่อภาพใช้เลขหน้าต้นฉบับ เช่น `page_005.jpg`
- กด **Cancel conversion** เพื่อหยุดงาน โปรแกรมตรวจคำขอยกเลิกระหว่างหน้าและหลังเรนเดอร์หน้า จึงอาจต้องรอขั้นตอนเรนเดอร์หรือบันทึกภาพปัจจุบันก่อน ภาพที่บันทึกแล้วจะเก็บไว้ PDF ที่ยังไม่เริ่มจะถูกยกเลิกด้วย
- หลังยกเลิก สามารถเปลี่ยนหน้าหรือค่าต่าง ๆ แล้วกดแปลงใหม่ได้ โปรแกรมสร้างโฟลเดอร์ใหม่เพื่อไม่เขียนทับภาพรอบก่อน
- ปุ่ม **Cancel conversion** ใช้พื้นหลังสีแดงเพื่อแยกจากปุ่มดำเนินงาน เมื่อกดแล้วเปลี่ยนเป็นสถานะ Cancelling และกดซ้ำไม่ได้
- งานแปลง PDF ทำใน process แยกจากส่วนควบคุมหน้าจอ และใช้ลำดับความสำคัญต่ำกว่างานปกติบน Windows เพื่อลดอาการหน่วงระหว่างแปลง โดยยังคงแจ้งความคืบหน้าและยกเลิกระหว่างหน้าได้

## หน้าต่างและโลโก้

- เมื่อปิดแอปตามปกติ โปรแกรมจำขนาด ตำแหน่ง และสถานะขยายเต็มจอของหน้าต่างหลักไว้ เปิดครั้งถัดไปจะคืนค่าเดิม หากตำแหน่งเดิมอยู่นอกจอจะปรับกลับเข้าสู่จอที่มีอยู่
- การปิดขณะเต็มจอเก็บขนาดหน้าต่างก่อนขยายไว้ด้วย จึงกด Restore แล้วกลับไปขนาดเดิมได้ การย่อไป taskbar จะไม่ทำให้เปิดรอบใหม่เป็นหน้าต่างที่ซ่อนอยู่
- โลโก้และไอคอนเมนูในหน้าต่างหลักใช้ SVG โลโก้หน้าจอโหลดใช้ PNG 512×512 ปรับขนาดตาม DPI และไอคอน Windows ใช้ ICO หลายขนาดตั้งแต่ 16 ถึง 256 พิกเซล

## จัดการหน้า PDF

1. เปิดเมนู **จัดการหน้า PDF** แล้วกด **เพิ่ม PDF** หรือลากไฟล์จาก File Explorer ลงหน้าจอ แต่ละหน้าจะแสดงเป็นการ์ดภาพย่อใน grid สลับเป็น list ได้จากปุ่มด้านขวาบน
2. คลิกภาพย่อหรือ checkbox เพื่อเลือกหลายหน้า ใช้ Shift + คลิกเพื่อเลือกเป็นช่วง และ **เลือกทั้งหมด** สำหรับหน้าที่แสดงอยู่ กรองตามชื่อไฟล์ได้โดยไม่เปลี่ยนลำดับส่งออก
3. ลากภาพย่อเพื่อเรียงหน้า รวมถึงข้ามเอกสาร ถ้าลากหน้าที่เลือกอยู่จะย้ายทั้งกลุ่มตามลำดับเดิม มีปุ่มย้ายก่อนหน้า/ถัดไปสำหรับใช้แทนการลาก
4. กดปุ่ม **หมุน / พลิก** บนการ์ด หรือใช้แถบเครื่องมือสำหรับหน้าที่เลือก เลือกหมุนซ้าย/ขวา 90°, หมุน 180°, พลิกซ้าย–ขวา (แนวนอน), พลิกบน–ล่าง (แนวตั้ง) หรือคืนค่าต้นฉบับได้ ผลลัพธ์ PDF ใช้มุมและการพลิกเดียวกับตัวอย่าง กด **ย้อนกลับ** หรือ Ctrl+Z เพื่อคืนการเรียง หมุน พลิก หรือลบล่าสุด เก็บประวัติได้ 25 ขั้นภายในรอบเปิดแอป การเพิ่ม/ล้างไฟล์เริ่มประวัติใหม่
5. กดแว่นขยายหรือดับเบิลคลิกภาพย่อเพื่อเปิด popup ตัวอย่าง มีปุ่ม + / −, **Fit page** และ **Fit width** ซูมด้วย Ctrl + ล้อเมาส์หรือจีบสองนิ้วเฉพาะภาพใน popup เลื่อนเพื่อดูส่วนอื่น และเปิดเมนูหมุน/พลิกได้จาก popup โดยเปิดแต่ละครั้งเริ่มจาก Fit page การซูมทั้ง WebView ถูกปิดเพื่อไม่ให้เมนูและปุ่มทั้งแอปขยายตามภาพ
6. แผงบันทึกด้านขวาเลือกส่งออก **ทุกหน้าที่จัดไว้** หรือ **เฉพาะหน้าที่เลือก** พร้อมจำนวนหน้าก่อนบันทึก จากนั้นเลือกวิธีจัดการ:
   - **รวมเป็น PDF เดียว** — รวมตามลำดับภาพย่อเป็น `merged.pdf`
   - **แยกตามไฟล์ต้นฉบับ** — สร้าง PDF หนึ่งไฟล์ต่อเอกสาร โดยใช้ลำดับหน้าที่จัดไว้ภายในแต่ละต้นฉบับ
   - **แยกทุกหน้าเป็น PDF** — สร้าง PDF หนึ่งไฟล์ต่อหน้าที่ส่งออก ชื่อไฟล์ระบุเลขหน้าต้นฉบับ
7. เลือกโฟลเดอร์ แล้วกด **บันทึก PDF** ผลลัพธ์แต่ละรอบอยู่ในโฟลเดอร์ใหม่ `organized/`, `organized_2/` ฯลฯ เพื่อไม่เขียนทับผลลัพธ์เดิม

คัดลอกหน้า PDF โดยตรง ไม่แปลงเป็นรูปภาพ จึงคงข้อความและกราฟิกเดิมไว้ งานทำใน process เบื้องหลังและกดยกเลิกได้เมื่อขั้นตอนปัจจุบันเสร็จ ในโหมดรวม/แยกตามต้นฉบับตรวจยกเลิกระหว่างเอกสารและก่อนบันทึก ส่วนแยกทุกหน้าตรวจระหว่างหน้า ไฟล์ PDF ที่บันทึกสำเร็จแล้วจะเก็บไว้

รายการหน้า ลำดับ มุมหมุน และการเลือกแยกจาก PDF to Image และยังอยู่เมื่อสลับเมนูภายในรอบที่เปิดแอป โหลดภาพย่อเฉพาะบริเวณที่เห็นและใกล้ตำแหน่งเลื่อน ทีละภาพ แคชไม่เกิน 120 ภาพ และถอดภาพที่อยู่นอกพื้นที่ออกจากการ์ดเพื่อลดหน่วยความจำ ไฟล์อ่านไม่ได้จะแจ้งเมื่อเลือกตัวกรองชื่อไฟล์นั้น ไม่มีการแก้ไขไฟล์ต้นฉบับ

เลือกหน้าจาก command line ได้ด้วย:

```powershell
.\.venv\Scripts\python.exe pdf_to_jpg.py "input\sample.pdf" --pages "1-3,5" --format png
```

## การเก็บข้อมูล

- การตั้งค่า PDF: `ui_settings.json`
- การตั้งค่า Heatmap: `heatmap_settings.json`
- ขนาด ตำแหน่ง และสถานะหน้าต่างหลัก: `workspace_settings.json`
- โฟลเดอร์ล่าสุดของเมนูจัดการหน้า PDF: `organizer_settings.json`
- ค่าเริ่มต้น Heatmap: `config.json`
- ผลลัพธ์เริ่มต้น: `output/` หรือโฟลเดอร์ที่เลือกในแต่ละเครื่องมือ

เริ่มด้วยการตั้งค่าเริ่มต้น เพื่อไม่ให้เขียนผลลัพธ์ลงโฟลเดอร์ต้นฉบับโดยไม่ตั้งใจ
Heatmap จะเติมเลขท้ายชื่อเมื่อไฟล์ส่งออกมีอยู่แล้ว
ระหว่างแปลง PDF หรือสร้าง Heatmap โปรแกรมจะรอให้งานเสร็จก่อนยอมปิดหน้าต่าง

## โครงสร้างและการทดสอบ

`main_app.py` เป็นตัวรวมหน้าต่างและส่งคำสั่งไปยัง `DocumentAPI`, `OrganizerAPI` และ `HeatmapAPI`
`ui/management.html` เป็นเมนูหลัก หน้าของแต่ละเครื่องมือแยกบริบท HTML/CSS/JS และใช้ Python bridge ร่วมกัน
`heatmap/` เป็นแกนคำนวณเดิม และ `pdf_to_jpg.py` เป็นแกนแปลง PDF เดิม
`organizer_app.py` ควบคุมงานจัดการหน้า PDF, `organize_pdf.py` คัดลอกหน้าตามตัวเลือก, `organizer_ui/` เป็นหน้าจอ และ `pdf_worker.py` แยกทั้งงานแปลงภาพและจัดการ PDF ไป process เบื้องหลัง
เวอร์ชันโปรแกรมระบุในไฟล์ `VERSION`

เครื่องมือตามคำสั่งยังใช้ได้ผ่าน `pdf_to_jpg.py` และ `heatmap_cli.py --config config.json`

```powershell
.\.venv\Scripts\python.exe -m unittest discover -v
.\.venv\Scripts\python.exe tools\smoke_management.py
.\.venv\Scripts\python.exe tools\smoke_pdf_workflow.py
.\.venv\Scripts\python.exe tools\smoke_window_settings.py
.\.venv\Scripts\python.exe tools\smoke_organizer.py
```

Smoke test เปิดหน้าต่างชั่วคราว ตรวจทั้งสองเครื่องมือ การสลับหน้า และการส่งออกจริง แล้วปิดเอง

`smoke_organizer.py` ตรวจ grid/list ภาพย่อ การลาก PDF เลือกหลายหน้าด้วย Shift ลากเรียงข้ามไฟล์ ลบ/ย้อนกลับ เมนูหมุน/พลิก popup พร้อม Zoom/Fit และ native Ctrl+wheel ที่ไม่เปลี่ยน WebView zoom ส่งออกเฉพาะหน้าที่เลือก เนื้อหาและมุมหมุนในผลลัพธ์ทั้งสามโหมด การยกเลิก การโหลดภาพตามตำแหน่งเลื่อน และ layout ที่ 1280×820 กับ 1080×700 ภาพหน้าจอเก็บใน `.runtime-tmp/` มี unit test เปรียบเทียบภาพก่อน/หลังพลิกและการหมุนร่วมกับ crop เดิม

`smoke_pdf_workflow.py` ตรวจการลากไฟล์ผ่าน native WebView2 bridge ทั้งหน้าหลักและ iframe การเลือกหน้าไม่ถูกต้อง การส่งออกทุกตัวเลือกใน dropdown การกดยกเลิกและเก็บภาพที่เสร็จแล้ว รวมถึง layout ที่ 1280×820 และ 1080×700 ภาพหน้าจอทดสอบเก็บใน `.runtime-tmp/` ซึ่งไม่รวมใน Git

วัดการตอบสนองก่อน/หลังแยก process ด้วย `.\.venv\Scripts\python.exe tools\benchmark_pdf_responsiveness.py` ใช้ PDF ทดสอบ vector หนาแน่น 3 หน้า ที่ 300 DPI ผลบนเครื่องพัฒนาพบช่วงสะดุดสูงสุดของ Python heartbeat ลดจาก 783.7 ms เหลือ 23.9 ms เวลาแปลง 3.25 และ 3.45 วินาทีตามลำดับ ตัวเลขนี้วัดความต่อเนื่องของส่วนควบคุมด้วยไฟล์สังเคราะห์ ผลกับไฟล์จริงและเครื่องอื่นอาจต่างกัน

ดูรายการเปลี่ยนแปลงใน [CHANGELOG.md](CHANGELOG.md)

สร้าง PNG/ICO ใหม่จากโลโก้ SVG ได้ด้วย `.\.venv\Scripts\python.exe tools\render_app_icon.py` เครื่องมือนี้เปิด WebView2 ชั่วคราวเพื่อเรนเดอร์ SVG แล้วปิดเอง
